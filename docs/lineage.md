# Lineage

This repository converges two states:

1. **Current phone ARK** — the runtime already operating on JANUS/ODIN.
2. **GA-ARK T2 Mobile Cyber Throne v1** — an additive operator-control profile.

The source-of-truth rule is deliberately conservative: reported names/version/install roots are declarations until verified against a captured device manifest and SHA-256 sealed source set.

The repository does not reinterpret the current phone runtime as obsolete. Promotion history must retain the predecessor, migration evidence, and rollback route.
