# 15 — Definition of Done

V1 is complete only when all are observed on a real JANUS or ODIN phone:
1. signed APK builds reproducibly and installs;
2. APK authenticates to Render without embedded privileged secrets;
3. Talk produces a real Atlas Mind/Resident GARI response;
4. Status reads live SAMI reconciled state;
5. Act submits a JANUS-governed command;
6. command reaches Packet/Workforce execution;
7. SECA/DevOS verifies the result;
8. ProofGrid emits a receipt;
9. native Thoth stores the proven runtime lineage;
10. SAMI reflects the updated state;
11. phone receives/speaks the proven result;
12. Android can select Atlas as Digital Assistant and invoke its assistant surface;
13. VISHVARUPA records fresh body/app attestation.

Until these pass, state remains IMPLEMENTED/STAGED rather than PROVEN.
