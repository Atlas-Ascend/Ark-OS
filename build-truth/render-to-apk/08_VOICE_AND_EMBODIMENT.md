# 08 — Voice & Embodiment

Phone capabilities replace the first-generation robot shell:
- microphone → speech input;
- speaker/TTS → Atlas voice;
- display → JANUS VIBE/Atlas face/state;
- haptics → acknowledgement/warning/success;
- camera → ARGUS/vision capability;
- GPS/IMU → body/context observations;
- notifications → asynchronous proof/work events.

Normalized embodiment actions include LISTEN, THINK, SPEAK, ACKNOWLEDGE, WARNING, ERROR, SUCCESS, SLEEP, WAKE, CAPTURE_IMAGE and SHOW_MESSAGE.

Embodiment events never bypass JANUS action policy.
