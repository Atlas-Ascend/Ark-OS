# GA-ARK-RENDER-TO-APK-001

## Decision

The first Atlas phone embodiment uses **Render → native APK** rather than moving the cognitive runtime onto the phone.

- Render remains primary Atlas runtime/execution ingress.
- Ark-OS owns the Android body/application lineage.
- Atlas Mind/Resident GARI remain cognition/identity.
- SAMI provides read-only reconciled resident state.
- JANUS PRIME remains execution authority.
- JANUS VIBE is the phone/operator surface.
- Thoth remains durable memory authority.
- VISHVARUPA remains physical-node/body truth authority.

## Acceptance

PROMOTED only after an APK is built, installed, selected as Android Assistant, invoked on a real JANUS/ODIN phone, reads live SAMI state, submits one bounded JANUS-governed command, and observes matching ProofGrid/Thoth completion.
