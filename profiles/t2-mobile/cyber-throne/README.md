# GA-ARK T2 Mobile Cyber Throne v1

Cyber Throne turns an existing T2 Mobile ARK node into an operator-control cockpit without replacing the installed ARK runtime.

## Capability surface

- **JANUS VIBE** — executive command UI.
- **ODIN** — state/health/telemetry UI.
- **Android body** — microphone, speaker/TTS, notifications, haptics, torch, sensors, camera/location where explicitly permitted.
- **Atlas Mind** — conversational interpretation/routing boundary.
- **Hypernet bridge** — remote node control over authenticated networking/SSH.
- **Packet OS / Workforce Spine** — governed command routing.
- **SECA/DevOS / ProofGrid** — verification and evidence return.
