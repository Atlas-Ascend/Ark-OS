# ADR-001: ARK OMEGA is a Cockpit, Not an Assistant

Status: ACCEPTED

Decision: ARK OMEGA owns human-machine interaction, system inspection, execution context selection, mission dispatch, recovery, and proof presentation. Atlas Mind may provide conversational cognition inside ARK OMEGA, but ARK OMEGA does not collapse into a chatbot.

Consequence: conversational responses are subordinate to operational state. The operator can inspect, override within policy, select peers, view evidence, and recover without depending on conversational output.
