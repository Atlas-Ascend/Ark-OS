# Accessibility and Responsiveness

TUI must operate at 80x24 minimum with graceful compression below that. No critical state is color-only. Status always includes text or symbol. All controls are keyboard reachable. Focus state is explicit. Motion can be reduced without losing state meaning.

Android/Termux targets one-hand readable portrait use, external keyboard use, and landscape dense mode. Web command center supports desktop widescreen, tablet, and narrow mobile inspection views.

Critical controls remain reachable without precision pointer input.
