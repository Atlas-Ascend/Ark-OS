# Information Architecture

## Global shell
- top status rail: estate health, trust, peer context, node count, worker count, alert count
- left domain rail: SYSTEM, FABRIC, RESOURCES, MISSIONS, COGNITION, PROOF, SECURITY
- center workspace: selected domain
- right context rail: active mission, selected node, active packet, current gate
- bottom command rail: hotkeys, command palette, connection state

## Domain model
SYSTEM: vessel identity, runtime, version, battery, storage, local services.
FABRIC: nodes, routes, transports, topology, peer states.
RESOURCES: CPU, RAM, GPU, storage, models, workers, capability advertisements.
MISSIONS: objectives, packet decomposition, queue, execution lifecycle.
COGNITION: Atlas Mind, GARI, Thoth, CaseGraph context and retrieval surfaces.
PROOF: SECA, DevOS, ProofGrid receipts, hashes, tests, deployments.
SECURITY: Medusa state, identity, permissions, trust, policy denials, credential health.
