# Operator State Machine

BOOT -> LOCAL_READY -> FABRIC_DISCOVERY -> TRUST_EVALUATION -> COCKPIT_READY

Cockpit mission states:
IDLE -> INTENT_RECEIVED -> AUTHORIZING -> PACKETIZING -> ROUTING -> QUEUED -> EXECUTING -> VERIFYING -> PROVING -> SEALED

Failure states:
ANY -> DEGRADED
AUTHORIZING -> DENIED
ROUTING -> NO_CAPABILITY
EXECUTING -> FAILED
VERIFYING -> REJECTED
PROVING -> PROOF_FAILED

Recovery paths:
DEGRADED -> RETRY | LOCAL_ONLY | ALTERNATE_PEER | RECOVERY_CONSOLE
FAILED -> REPAIR_PACKET -> EXECUTING
REJECTED -> REPAIR_PACKET -> EXECUTING

No success state may be displayed without a corresponding signed or locally attributable event.
