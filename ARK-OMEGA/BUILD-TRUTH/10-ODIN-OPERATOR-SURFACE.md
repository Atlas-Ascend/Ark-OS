# 10 // ODIN Operator Surface

Canonical CLI namespace: `atlas`.

Commands: `atlas status`, `atlas peer`, `atlas nodes`, `atlas resources`, `atlas capabilities`, `atlas send`, `atlas fetch`, `atlas sync`, `atlas packet`, `atlas dispatch`, `atlas workforce`, `atlas mission`, `atlas proof`, `atlas replay`, `atlas doctor`.

Peer modes: `atlas peer auto`; `atlas peer janus`; `atlas peer eden`; `atlas peer hypernet`; `atlas peer <node>`.

Mobile UX must remain operable over intermittent links. Mutating commands enter the durable local outbox before transmission.
