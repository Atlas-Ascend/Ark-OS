# 08 // Hardened SDLC

Loop: Discover -> Reverse Engineer -> Specify -> Threat Model -> Contract -> Design -> Implement -> Static Analyze -> Unit Test -> Integration Test -> Fault Inject -> Security Test -> Performance Test -> Package -> Canary -> Verify -> Deploy -> Observe -> Receipt -> Replay -> Promote/rollback -> Learn.

Every promotion requires Build Truth delta, test evidence, security result, rollback instructions and ProofGrid receipt. Failed verification blocks promotion.

Branches are accession/candidate surfaces; `main` remains canonical until gates pass.
