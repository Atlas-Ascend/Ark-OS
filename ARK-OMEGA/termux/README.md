# ODIN // ARK OMEGA Termux UX

Professional full-screen ARK OMEGA field command console for Termux.

## UX model
Firmware/BIOS discipline + mission-control observability. No fake telemetry. Every remote state is explicitly ONLINE, DEGRADED, OFFLINE, UNBOUND, or QUARANTINED.

## Global hotkeys
- F1 Help
- F2 Peer menu
- F3 Nodes
- F4 Resources
- F5 Missions
- F6 Packets
- F7 Proof
- F8 Events
- F9 Doctor
- F10 Command palette
- Ctrl+R Refresh
- Ctrl+Q Quit
- 1 AUTO / 2 JANUS / 3 EDEN / 4 HYPERNET

Launch with `ark` after installation.
